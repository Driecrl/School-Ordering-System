# QCU Canteen Presentation Demo

Open `outputs/qcu-canteen-presentation-demo.html` in a browser to present the student ordering and canteen staff flows.

The standalone demo includes student/staff sign-in screens, a temporary PIN change screen, a menu and cart, pickup-order status, and a staff order desk. It uses sample data kept in the open page, so there is no database setup for the presentation.

Demo sign-ins appear on the first screen:

- Student: `20260001` with PIN `123456`
- Staff: `QCUSTAFF01` with PIN `123456`

The first sign-in asks for a new PIN. Demo PIN changes and orders last only until the page is reloaded. Do not enter real student or staff information.
